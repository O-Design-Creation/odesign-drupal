# Documentation utilisateur — Atelier O Design

> Bienvenue, Océane ! Ce guide est fait pour vous accompagner au quotidien dans la gestion de votre boutique. Chaque section répond à une question concrète : "Comment faire X ?"
> Vous n'avez pas besoin de connaissances techniques pour l'utiliser.

---

## Comment accéder à votre boutique

**Adresse de connexion** : [votre site]/user/login
**Votre tableau de bord** : `/admin/boutique`

Une fois connectée, vous retrouvez votre tableau de bord avec les raccourcis vers toutes les sections ci-dessous.

## En cas de problème

Si quelque chose ne fonctionne pas comme décrit dans cette documentation :

1. Vérifiez que vous êtes bien connectée avec votre compte `gestionnaire_boutique`
2. Essayez de recharger la page (touche F5 ou Ctrl+R)
3. Si le problème persiste, notez exactement ce qui s'est passé (quelle page, quel message d'erreur) et contactez votre prestataire technique

> ⚠️ **Attention** : Ne communiquez jamais votre mot de passe à qui que ce soit, même à votre prestataire technique. Un prestataire légitime n'a pas besoin de votre mot de passe pour intervenir sur le site.
